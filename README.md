# NeuroTrack: Protecting Brain Health Earlier

Working prototype for the Future Health Digital Innovation Challenge, Population Health, Challenge 08.

**Live app:** open `index.html` through GitHub Pages. No login is needed, and every screen works as a guest.

- 10 screens: overview, programme dashboard (timeline playback, filters, referral flow, heatmap, ROC threshold explorer), participant journey, live session scoring, assessment tasks, clinician review queue, validation and fairness, safety and governance, user guide, technical documentation.
- Runs entirely in the browser. `engine.js` is the scoring engine, ported from the Python prototype and matching it to within 0.0004 z.
- All participants are synthetic. This is a research prototype, not a medical device.

Full documentation: `docs/NeuroTrack_Technical_Documentation.html` (or the PDF next to it).
